# Memento

## Descripción:

Memento es una aplicación web diseñada para ayudar a las personas a organizar sus tareas cotidianas, recordar cuándo deben realizarlas y llevar un seguimiento de su estado.

La aplicación permite centralizar las tareas en un mismo lugar, consultar cuáles están pendientes y cuáles se han completado, y programar recordatorios para reducir los olvidos en el día a día.

Memento nace de la necesidad de facilitar la organización de las responsabilidades cotidianas, desde tareas domésticas hasta otras actividades que requieren cumplir determinados horarios o rutinas.

## Objetivos del proyecto:

- Facilitar la creación y organización de tareas.
- Permitir programar fechas, horas y repeticiones.
- Ayudar a recordar las tareas mediante recordatorios.
- Permitir marcar las tareas como realizadas y consultar su estado.
- Ofrecer una interfaz clara, intuitiva y adaptable a dispositivos móviles y ordenadores.

## Tecnologías:

El proyecto se desarrollará utilizando el stack MERN:

- **MongoDB:** base de datos.
- **Express.js:** framework para desarrollar la API del servidor.
- **React:** biblioteca para construir la interfaz de usuario.
- **Node.js:** entorno de ejecución del servidor.

También se utilizarán herramientas de desarrollo y control de versiones, como Git y GitHub.

## Diseño:

La interfaz de Memento se diseñará teniendo en cuenta la facilidad de uso, la claridad de la información y la adaptación a diferentes tamaños de pantalla.

El proceso de diseño incluirá investigación de usuarios, definición del alcance del proyecto, creación de flujos de usuario, sitemap, wireframes y prototipos navegables.

## Documentación:

La documentación del proyecto incluirá los siguientes archivos:

- [`BRIEF.md`](BRIEF.md): definición del problema, alcance, personas, criterios de éxito y restricciones del proyecto.
- [`CHANGELOG.md`](CHANGELOG.md): registro de los cambios y del uso de herramientas de inteligencia artificial durante el desarrollo.

## Estado del proyecto:

Actualmente, Memento se encuentra en su fase inicial de planificación y diseño. Se están definiendo las necesidades de los usuarios, el alcance de la primera versión y la estructura de la aplicación antes de comenzar su implementación.
